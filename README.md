# Müzik

Linkten şarkı indirip çevrimdışı dinleme uygulaması (Kotlin + Jetpack Compose + Media3).

## Özellikler
- Doğrudan ses dosyası linki (.mp3, .m4a, .ogg, .flac…) yapıştırıp indirme, ilerleme çubuğuyla
- Tarayıcıda linke uzun bas → **Paylaş → Müzik** ile hızlı ekleme
- Kütüphanede ad/sanatçıya göre arama (dosyadaki etiketler otomatik okunur)
- Arka planda çalma, bildirim + kilit ekranı kontrolleri, kulaklık çıkınca durma
- Çalma listeleri, karışık çalma, tekrar modu

Not: /Spotif linkleri çalışmaz.
